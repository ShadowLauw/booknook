# BookNook 📚

BookNook is a mobile application that helps you manage your personal library, discover new books, and track your reading.  
The app combines scanning, search, and AI-powered recommendations to provide a seamless reading experience.

⚠️ **Ongoing project** – new features are actively being added.

---

## Features

### Library & Collections

- Keep track of your personal library and wishlist
- Add new books by scanning ISBN codes with your device camera
- Search for books and view their details, including cover, authors, description and more

### Book Discovery & Recommendations

- Receive personalized book suggestions powered by AI
- Explore recommended books directly from your home page

### Account & Navigation

- Create an account and manage your profile
- Navigate easily between library, wishlist, recommendations, and book pages

### User Experience

- Smooth and responsive interface
- Quick search inputs for fast access to books
- Clean layout with clear feedback for actions like adding books

## Technologies

- **Frontend**: React Native + Expo
- **Backend**: Next.js on Vercel
- **Database**: Supabase
- **Routing**: Expo Router
- **Validation**: Zod
- **UI Styling**: Nativewind
- **APIs**: Google Books API, OpenAI API
